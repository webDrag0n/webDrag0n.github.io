HOT · 具身智能
DreamTrue：具备反事实后训练的动作忠实机器人世界模型
来自 HuggingFace Daily Papers 热门。DreamTrue 是一个多视角、跨本体的机器人世界模型，目标是在视频预测层面同时做到动作忠实与物理合理。论文指出现有机器人数据集存在两大瓶颈——标定误差破坏动作跟随、失败交互样本稀缺导致结果偏向成功案例；作者通过反事实后训练机制补充失败轨迹，使模型对"未成功"的物理后果也能合理预测，为后续 sim-to-real 与 policy 评估提供更可信的 simulator。

🧠LLM / 推理与对齐
ArXiv · cs.CL
MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement
MiMo 系列最新报告，提出通过规模化 RL 计算推动全模态大模型的自我改进。RL 之前先在大规模多模态语料上进行 mid-training 以扩展探索空间，再进入 RL 阶段进行能力收敛。报告给出了 RL 训练规模与下游能力之间的 scaling 关系，是当前 omni-modal 自我改进范式的重要参照。
RLOmni-modalScaling
ArXiv · cs.CL
U-Space: Uncovering When and Why Uncertainty Arises in Language Models
聚焦 LLM 的不确定性与"何时该拒答"。论文剖析语言模型即便输出错误结论也能以流畅且权威的语气自我合理化的现象，提出 U-Space 框架用于定位不确定性产生的语境与原因，为高风险场景下的可信决策、人工介入触发提供量化依据。
UncertaintyTrustworthy AI
ArXiv · cs.CL
OnTrack: Real-Time Monitoring and Intervention in LLM Agent Trajectories via Streaming Structure-Aware Optimal Transport
针对长时程 Agent 缺乏实时防护的问题，OnTrack 将 agent 轨迹建模为流式结构感知最优传输问题，在每一步上比对当前轨迹与"安全模板"分布，实现毫秒级监测与干预，优于事后日志审计与外部 safeguard agent。对交易、IT 运维等高风险 agent 部署具有直接参考价值。

👁️多模态 / VLM
ArXiv · cs.CV / cs.CL
FastBench: Can Streaming VLMs Perceive High-Dynamic Real-World Streams?
现有流式 VLM benchmark 多聚焦低动态场景。FastBench 针对高动态视频流提出更严苛的评测：在固定 context 预算下，模型需要在时间历史、空间分辨率、时间粒度之间权衡，1–2 FPS 的稀疏采样会错过关键事件。该 benchmark 有望成为衡量"实时视频理解"的新基线。
Streaming VLMBenchmark
ArXiv · cs.CV / cs.CL
SpaceCast-Bench: Evaluating Predictive Spatial Reasoning in Vision-Language Models
区别于已有"读出可见关系"的空间感知 benchmark，SpaceCast-Bench 聚焦预测性空间推理——从观测中重构场景、预判干预带来的变化、推理不可见结果。这是对真实空间智能更贴切的刻画，揭示了当前 VLM 在前瞻推断上的系统性短板。
Spatial ReasoningVLMBenchmark
ArXiv · cs.CV / cs.CL
WOVEN: Weaving Visual World Modeling into Multimodal LLMs
作者假设 MLLM 在空间、具身、物理、时间推理上的失败源于共同的"视觉转移推理"缺陷，并将该能力作为可学习的训练原语织入 MLLM。WOVEN 验证了不同模型可从不同监督源中学习这一原语，为通用多模态推理提供了一个统一视角。
Visual World ModelMLLM
🦾具身智能 / 机器人
ArXiv · cs.RO
Dex-One2Many: Learning Dexterous Manipulation from a Single Human Demonstration
挑战"一条人类视频 → 多种灵巧操作"的少样本学习问题。论文指出现有方法过度模仿演示动作，导致对初始位姿、目标位置变化泛化不足。Dex-One2Many 通过解耦任务语义与运动细节，使机器人能将单一人类演示迁移到多样化任务实例。
One-shot ImitationDexterous Manipulation
ArXiv · cs.RO
VersaCamVLA: Camera-Configurable VLA Policies for Robotic Manipulation
针对 VLA 模型对训练时相机位姿的强依赖问题，VersaCamVLA 提出可在部署时灵活改变相机数量与位置的策略架构，显著降低对固定硬件配置的要求。这对 VLA 在真实工厂/家庭场景的规模化落地具有直接工程价值。
