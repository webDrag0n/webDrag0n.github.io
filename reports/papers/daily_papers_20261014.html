GroundingPI: A Grounding Foundation Model towards Physical Intelligence with Visual Primitives
提出 4B 参数的视觉定位基础模型 GroundingPI，面向物理智能场景下的精确定位需求——在杂乱环境、微小目标条件下仍能确定"哪个物体是目标、目标在何处"，且推理速度足以支撑闭环控制。论文指出现有 VLA 与世界-动作模型所依赖的通用视觉-语言骨干在此类场景下仍不可靠，GroundingPI 以视觉原语（visual primitives）为核心重构定位能力，为下游操作策略提供高质量感知底座。
多模态/VLM 具身智能 Visual Grounding
HuggingFace 日榜 Top 2 · 215 upvotes
Thinking Inertia: LLMs Keep Thinking When Told Not To
系统研究大语言模型的"no-thinking"行为。作者指出既有工作以"关闭思考模式"或"无长思维链"作为 no-thinking 的代理指标均不可靠，并提出新的度量框架。实验揭示 LLM 存在"思维惯性"——即使被显式要求不思考，模型仍会延续推理行为。该研究对推理时计算控制（inference-time compute control）与高效部署具有直接意义。
LLM 推理效率 行为分析
arXiv 2610.13361 · cs.CL · HuggingFace 日榜 Top 3
AgentSWE: Can Coding Agents Build the Agent You Actually Want?
针对"由编码智能体构建用户所需智能体"这一新兴委托范式，提出基准 AgentSWE。论文指出，现有评估均未检验被交付的智能体是否真正忠实于构建需求，而非仅"看起来可用"。AgentSWE 填补了这一评估空白，对智能体自动生成（agent-generated agents）的可靠性给出可量化的检验框架。
智能体评估 Benchmark 代码生成

Scaling Agentic Data for Long-Horizon Terminal Intelligence
面向终端智能体（terminal agents）从局部操作走向真实世界专业任务的演进，研究长时程智能体轨迹数据的规模化构建。短轨迹仅能演示命令与工具调用，无法展现智能体如何通过探索积累证据、依据反馈持续调整策略并将中间结果转化为最终交付物。该工作系统化地解决高质量长时程轨迹数据的获取与规模化问题。

GroundAnything: Reconciling Parallel Decoding with Precise Visual Grounding at Flash Speed
将视觉定位重新表述为"视觉证据提取"问题：物体、位置与空间关系由图像与查询联合约束，其依赖关系并不蕴含内在的从左至右生成顺序。基于该洞察，作者以双向并行解码替代自回归串行预测，在保持定位精度的同时显著降低延迟，实现"极速"（flash-speed）视觉定位。与 GroundingPI 共同构成当日定位方向的双响。
并行解码 Visual Grounding 推理加速

Multi-Stream Attention Residuals
将 Attention Residuals（沿网络深度轴的单流 softmax 注意力）推广为多头深度注意力机制 MSAR。借鉴序列轴多头注意力的成功经验，该方法在深度维度上实现内容依赖的多流检索，带来显著性能提升，为深层架构中的跨层信息路由提供了新的结构化机制。
架构创新 Attention

Splat2Act: From Captured Scenes to Personalized VLA Manipulation
面向家庭与办公室场景下的个性化操作需求：用户期望通用操作策略能够识别并抓取"自己的"物体。Splat2Act 从捕获的场景重建（3D Gaussian Splatting 表示）出发，将场景先验注入 VLA 策略，实现从场景捕获到个性化操作的闭环，是通用操作策略落地个人环境的重要一步。

Chronos Policy: Learning Robot Policies on Physical Time
指出现有机器人策略将感知与控制转换为固定频率的观测-动作序列，物理时间仅隐式编码于序列位置中。Chronos Policy 直接在物理时间上学习策略，使时间信息显式化，提升策略在变速控制与时序敏感任务中的表现，为时序建模提供了新的策略学习视角。
