arXiv 2610.22276 · HuggingFace Daily Papers 354 ▲
MJev-Spatial: System One Spatial Intelligence via Native Attention Matching
空间智能要求智能体以交互速率完成「哪个空间关系成立、物体有多远、该放在哪里」等判断。现有 VLM 依赖自由文本生成，需支付自回归解码与答案解析成本，尽管输出空间本身极为紧凑。MJev-Spatial 通过原生注意力匹配直接输出结构化空间判断，将空间推理从「System 2」式慢思考压缩到「System 1」式快反应，为具身智能的实时决策提供了新路径。

arXiv 2610.22200 · HuggingFace Daily Papers 316 ▲
OpenGCUA: Toward a Fully Open Stack for Generalist Computer Use
计算机操作（Computer Use）正从纯 GUI 交互扩展到融合视觉与程序化接口的通用任务执行。OpenGCUA 定义了通用计算机操作智能体（GCUA），并提供覆盖数据、训练与评测的全开源技术栈，对标 GPT 级闭源实现，显著降低了社区进入该方向的门槛，有望成为 Computer-Use Agent 研究的标准基座。

Hot · RL 后训练
arXiv 2610.21601 · HuggingFace Daily Papers 668 ▲
Waypoint-OPD: Transferring RL-Induced Policy Shifts via Gated On-Policy Distillation
策略偏移蒸馏复用教师模型在 RL 前后的 log 概率差作为学生轨迹上的监督信号，但端点偏移无法揭示局部动作偏好在训练中的一致性演化。Waypoint-OPD 引入中间路径点与门控在策略蒸馏，更细粒度地迁移 RL 诱导的策略变化，为「蒸馏 RL 收益」这一后训练范式提供了更可靠的传输机制。668 票的社区热度印证了该方向的关注度。
668 ▲ 今日最热 RL 蒸馏 On-Policy Distillation 后训练
Hot · 多智能体协作
arXiv 2610.22319 · cs.AI · DeepMind
A team of Gemini 4 Argon agents beats Minecraft
DeepMind 团队将 4 个 Gemini 4 Argon 智能体放入沙盒 Minecraft 生存世界，目标只有一个：击败末影龙。每个智能体通过开源库 Mineflayer 控制玩家，经游戏内聊天与共享记忆协调——无人分配角色、无人编写游戏逻辑，所有程序均由智能体自行规划、编写与调试。这是多智能体系统中 emergent coordination 的一次生动展示。

arXiv 2610.22350 · cs.AI / cs.SE · HuggingFace Daily Papers 285 ▲
FDE-Gym: The Last Mile of AI Delivery
现有 Agent 基准评测的多是定义明确的任务，而真实客户交付截然不同：前置部署工程师必须澄清模糊需求、在活跃系统中操作并发现未声明的约束。FDE-Gym 提供 95 个来自 20 个客户场景的端到端交付任务，将评测对准「最后一公里」交付能力，是从实验室指标迈向工程现实的重要一步。

arXiv 2610.20939 · HuggingFace Daily Papers 154 ▲
MAI-Gym: An Open All-in-One Platform for GUI Agent Evaluation and RL Training
可验证奖励的在线 RL 已在数学、代码与工具使用上取得快速进展，但 GUI 智能体受限于交互环境的高成本。MAI-Gym 提供覆盖移动端与桌面端的一体化开源平台，将评测、数据采集与在线 RL 训练整合于统一框架，补齐了 GUI Agent 规模化训练的关键基础设施。

Self-Evolving Agent Harness
Harness 自演化在模型权重固定的前提下修订智能体的软件脚手架——提示词、记忆、工作流与可执行组件。作者将这一反馈驱动过程形式化，区分更新目标与提案/准入机制，为「不改权重、改脚手架」的 Agent 自我改进路线提供了清晰的概念框架。

Mosaic: Multi-Session Agentic Reinforcement Learning
现有 Agentic RL 假设单会话轨迹，但上下文压缩与子智能体分叉等技术会产生跨多会话的轨迹，造成训练假设与推理执行的不匹配。Mosaic 提出多会话 Agentic RL 框架，直面这一日益普遍的工程现实，为长程 Agent 训练扫清障碍。
54 ▲ Agentic RL 多会话

Learning Self-Orchestration in Decentralized Agent Swarms
智能体集群的能力取决于个体成员及其协调方式，但现有多智能体系统通常在固定编排结构内训练。本文提出基于市场的后训练（MPT）框架，联合学习动作策略与自编排机制，让去中心化智能体集群自己学会如何组织协作。

Each Reward to Its Relevant Tokens: Reward-Specific Token-Level Credit Assignment
多奖励 RL 训练中，GDPO 等方法分别归一化各奖励以保持优势区分度，但仍将每个奖励的优势均匀分摊到整条轨迹。本文提出奖励特定的 token 级信用分配，把「哪个奖励」精确对应到「哪些 token」，显著提升多约束场景下的训练效率与信号质量。

Behavioral Compositionality of Sparse Autoencoder Representations
稀疏自编码器以稀疏线性解码特征表示模型激活，但特征的下游行为效应未必可加。作者提出 SAE Additivity Residuals（SAR），度量未被给定交互阶数解释的行为变异，为机制可解释性研究提供了严格的组合性检验工具，揭示 SAE 特征在行为层面的系统性非线性。

VLA-Δ: Learning Physical State Transition for Vision-Language-Action Models
