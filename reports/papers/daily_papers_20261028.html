arXiv 2610.35868 · cs.AI · 检索增强
Retriever-Free Retrieval: Navigating Documents with Decision Models
提出 DecisionRAG：抛弃传统的词匹配/向量检索，用预训练语言模型作为"决策模型"在单次前向传播中联合评估候选分支，直接在文档树中导航定位信息，解决"检索器找不到，生成器再强也没用"的能力不对称问题。
💡 解读：RAG 架构的一条激进路线——把检索本身也交给大模型决策，值得观察其在长文档场景的实测表现。

arXiv 2610.35862 · cs.RO · 人形机器人操作
Learning Force-Reactive Humanoid Loco-Manipulation (FLORE)
许多日常任务需要同时控制接触力与运动。FLORE 框架通过两支带力传感的 UMI 式手持夹爪采集"无机器人"示范（手部运动 + 接触力/力矩），学习力响应式的人形机器人移动操作，实现双手与全身协调的力控。
💡 解读：力控是人形机器人进入真实产线的关键短板，"无本体数据采集 + 力觉示范"是一条低成本扩展路线。

Pretraining Knows What, Simulation Teaches How: Compositional Generalization in a Sim-Trained Robot Agent
提出 Zero-real Agent Policy（ZAP）：用 27B 预训练 VLM 提供世界理解与推理（"知道做什么"），再通过简单工具 harness + SFT + GRPO 在仿真中教会小型 VLM 控制机器人（"知道怎么做"），实现组合泛化。
💡 解读："预训练给常识、仿真教技能"的分工配方，为零真机数据训练机器人策略提供了可复现范式。

arXiv 2610.35801 · cs.LG · 强化学习
FOCUS: Active Critic Learning for Long-Horizon Language Model Agents
针对长程 Agent 的稀疏结果奖励问题，FOCUS 通过"选择性分支"（selective branching）主动学习 Critic：只在最有信息量的轨迹点上花费延续采样预算，兼顾价值估计精度与计算成本。
💡 解读：长程 Agent RL 的信用分配难题又添新解，"把采样预算花在哪"比"采多少样"更关键。

arXiv 2610.35804 · cs.CL · 推理加速
Learning When to Commit: Schedule Distillation for Fast Diffusion Language Models
扩散语言模型（dLLM）可并行生成多 token，但需要多轮解码。本文指出：高效生成不仅取决于哪些 token 好预测，更取决于"提交"它们对预测其余位置的帮助，并据此提出调度蒸馏方法加速解码。
💡 解读：dLLM 推理加速进入"提交策略学习"阶段，并行解码的实际可用性持续提升。

I-HITL: Inalienable Human-in-the-Loop
针对 Agent 日益擅长绕过护栏的问题，提出"不可剥夺的人机回环"（I-HITL）协议：从机制上保证 Agent 只有在获得显式人类批准后才能发起关键动作，即"人类在环"不可被 Agent 自身移除。
