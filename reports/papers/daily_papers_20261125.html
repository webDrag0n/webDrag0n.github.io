HOT · 学术焦点
WorldLeague: Benchmarking Physical Agency（HF +87）
提出跨 Blender 操作、复杂视频游戏、机械臂操控等多域统一的物理 agency 基准，回答「今天的 AI 系统究竟能自主完成多大范围的物理任务」。涵盖从纯软件到真实硬件的多档难度。
编辑点评：当 Agent 评测在软件任务上趋于饱和，「物理 agency」成为新的试炼场。WorldLeague 把 Blender、游戏和机械臂放进同一坐标系，让我们第一次能横向比较同一个模型在数字世界与物理世界中的能力差。

RUIBench: What Makes a Good Robot-Use Interface?
Show Lab 等提出 RUIBench，系统评估「机器人-使用接口（RUI）」设计对基础模型物理任务执行可靠性的影响，主张 RUI 是被严重低估的关键变量。

arXiv 2611.30898 · cs.RO · HF +23
World Models as Native Latent Action Models
利用大规模第一人称视频与异构机器人数据本身缺少动作标签或缺乏统一动作空间的问题，学习「潜动作（latent action）」让 world model 直接在原始视频上训练控制策略。
编辑点评：「潜动作」是 2026 年下半年机器人学习最重要的概念之一——它绕开了动作空间不统一的历史难题，让 world model 第一次可以直接「喝」互联网视频这口最大的数据井。

arXiv 2611.31154 · cs.LG · HF +10
Attention Latent Feedback
在自回归解码中，前序 token 的深层表征已被计算，但当前 token 的浅层无法直接读取。本文提出在注意力中引入 latent feedback 通路，让浅层能利用深层已有信息。
编辑点评：这是对 transformer 解码路径的一次「修补式」创新——不动主架构、只加反馈连接就能拿到加速与质量收益，工程友好度极高，预计会快速被推理框架社区吸收。

WeaveVLA: 3D Relational Grounding for Vision-Language-Action Models

arXiv 2611.31205 · cs.RO
ACAP: Asynchronous Coding Agents for Efficient Robot Control
Coding agent 可以在执行过程中构建和修改机器人行为，但单一 agent 串行处理所有任务会拖慢独立子任务。ACAP 把多个编码 agent 异步化并行执行，加速机器人闭环控制。
编辑点评：「用 LLM 写代码控制机器人」已经从噱头走向系统研究，异步多 agent 是必然演进方向。这篇文章的架构思路和软件工程的 async runtime 一脉相承，跨学科迁移做得很自然。
