AdvSim2Real: Training Web Agents Against Adaptive Prompt Injection in a Web World Model
Web 智能体在执行用户请求时必须读取第三方页面内容，因而天然暴露于提示注入攻击之下。该工作构建了一个 Web 世界模型用于模拟自适应注入攻击，并在此环境中对智能体进行对抗训练，突破了现有静态防御难以应对自适应攻击者的局限，为智能体安全训练提供了可扩展的仿真范式。
