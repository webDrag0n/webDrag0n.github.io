Hunyuan-A13B Technical Report
腾讯混元发布 A13B 开源大模型技术报告：基于 Mixture-of-Experts 架构，总参数量 80B、推理时仅激活 13B，在能力、计算效率与部署成本之间取得平衡。模型在 20T token 经严格过滤的语料上预训练，并强化 STEM 数据配比以提升事实可靠性与推理能力；后训练阶段结合高质量 SFT 与大规模强化学习。该报告已登上 HuggingFace Daily Papers 榜单。

arXiv 2609.26780 · HuggingFace Daily Papers
SpeakerMem-R1: Speaker-Centered Dual-Track Memory for Multi-Party Dialogue
针对多方对话场景下的长程记忆问题，提出以说话人为中心的双轨记忆机制，区分"谁说了什么"、陈述对象、个体间相互认知与群体共享信息及其随时间的演化。实验表明现有通用 LLM 记忆系统在多方设定下易丢失人物与群体关系，该方法显著改善了跨线索整合能力。
Agent 记忆多方对话LLM
arXiv 2609.27334 · HuggingFace Daily Papers
Just-in-Time Memory: Learning to Curate Task-Adaptive Memory for LLM Agents
指出现有 Agent 记忆系统在写入时即固化记忆内容（反思、工作流、技能等），导致在未来查询未知的情况下不可逆地丢弃信息。该工作提出"即时记忆"范式：延迟记忆策展至查询时刻，根据具体任务从原始轨迹中自适应地组织记忆，避免查询无关的摘要瓶颈。

arXiv 2609.26355 · HuggingFace Daily Papers
PACT: From Credit Assignment to Critic Alignment
针对 RL 后训练中 token 级信用分配缺乏公认数学定义的问题，提出完备性、前缀一致性与中立性三条正则条件，并证明其唯一确定 token 级信用。该刻画为解释现有算法的现象提供了统一理论基础，并可将信用分配与 critic 对齐纳入同一框架。
RLHF/RLVR信用分配理论
arXiv 2609.28385 · cs.AI
When and Where to Trust the Teacher: Unifying On-Policy Distillation and GRPO through Entropy-Calibrated Credit Assignment
RLVR 仅通过最终答案正确性监督数学推理，缺乏 token 级指导；在线蒸馏（OPD）虽提供稠密反馈，但教师偏好未必对应正确性。该工作通过熵校准的信用分配统一 OPD 与 GRPO，在"何时、何处信任教师"这一问题上给出了系统性的解决方案。
GRPO蒸馏推理
arXiv 2609.27891 · HuggingFace Daily Papers
Schrödinger's Code Repository: Have LLMs Learned SWE-bench or Memorized It?
系统考察 LLM 在 SWE-bench 上的高表现究竟源于真实的软件工程能力还是对基准数据的记忆。该研究对当前代码智能评测的有效性提出方法论层面的质疑，对基准设计与污染检测具有参考价值。

arXiv 2609.28256 · HuggingFace Daily Papers
MemBodied: Recurrent Associative Memory for Vision-Language-Action Models
现有 VLA 策略大多不保留当前观测之外的情节级信息，在历史依赖型操作任务上表现受限。MemBodied 为 VLA 引入循环联想记忆，在不无限膨胀上下文的前提下保留并利用过去观测，改善需要跨时间信息整合的操作任务。
VLA具身智能记忆机制
arXiv 2609.28393 · cs.RO
PointCast: One World Model for Rigid, Articulated, and Deformable Object Manipulation
提出点集世界模型 PointCast，以物体与末端执行器上的 3D 点集为状态表示，免网格、拓扑无关，统一覆盖刚体、铰接体与可变形体的操作预测。每个点保持身份一致性并受监督，为通用机器人操作的世界模型提供了简洁而通用的建模范式。
世界模型机器人操作
arXiv 2609.28429 · cs.RO
Watch, Recall, Act: Always-On Robots in Concurrent Embodied Streams
面向"常驻在线"机器人：指令随时到达与失效、场景持续变化、自身历史行动改变后续推理基础。该工作指出现有动作模型面向固定指令与单步推理的假设与现实脱节，提出在持续并发具身流中进行观察—回忆—行动的任务设定与基准。
