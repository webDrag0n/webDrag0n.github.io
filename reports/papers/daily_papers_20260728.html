The Regression Tax: Decomposing Why Skills Help and Hurt LLM Agents
在近 6000 次实验中发现：给 LLM Agent 添加技能可能导致性能倒退（Regression），甚至比不加技能更差。论文识别出三种倒退模式——技能描述渗透、接地位移、验证位移——指出当前技能过度强调过程指导，却忽视了更关键的接地与验证环节。这对 Agent 设计方法论有重要启示。
