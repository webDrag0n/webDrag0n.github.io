📄论文精选（arXiv / HuggingFace Daily Papers）
arXiv 2610.28626 · cs.RO
UniWALM: Unified World Action Language Model for Embodied Robot Control
提出统一的世界-动作-语言模型，在单一共享表征中同时学习视频、动作与语言，每种模态既作条件信号又作监督目标，验证联合生成语言能否改善操作控制。
「世界模型 + VLA + 语言」三位一体是具身大模型的收敛方向，UniWALM 是这条路线的又一有力实证。
具身智能世界模型VLA
HuggingFace Daily · 4 票
Self-Credit: Credit Assignment for Long-Horizon Agentic RL via Intra-group Rescaling
针对长程 Agentic RL 中稀疏奖励导致的信用分配难题，Self-Credit 通过组内重缩放，从稀疏结果奖励中自生成稠密监督信号：rollout 时策略模型生成带引用的摘要，回溯定位关键步骤。
让模型自己给长程轨迹「记账」，是稀疏奖励 Agent 训练的务实解法，比训一个独立过程奖励模型便宜得多。
Agent RL信用分配
HuggingFace Daily · 4 票
Training the Whole Agent, Not Just the Model (HarnessAdapt-RL)
训练编码 Agent 时通常只更新策略而固定 harness。HarnessAdapt-RL 在 RL 过程中同时调整策略与脚手架：冻结教师针对有缺陷的修复策略生成任务级机制技能，并处理跨任务反复出现的交互问题。
「脚手架也是可学习参数」——Agent 工程开始把工程构件纳入训练闭环，这可能比堆模型规模收益更快。
Agent训练方法
arXiv 2610.28577 · cs.CL
Cache Engineering for Agents
随着 Agent 轨迹增长，KV cache 的 I/O 与存储成为主导成本，甚至超出最大上下文长度。本文系统讨论面向 Agent 的缓存工程，区别于以往靠裁剪/摘要历史的上下文工程。
长程 Agent 的成本瓶颈正从「算力」转向「显存搬运」，缓存工程会是接下来 Agent 基础设施的热门赛道。
推理优化KV Cache
arXiv 2610.28601 · cs.AI
Evolving Agent Interfaces
计算机操作 Agent 受限于人类手工设计的接口（逐格填表格 vs 一行代码）。作者主张接口设计本身应当自动化进化，让 Agent 自主选择何时用何种接口。
接口不该是给 Agent 的「施舍」，而该由 Agent 自己进化出来——这个视角可能重新定义 computer-use 的工程范式。
Computer UseAgent 接口
arXiv 2610.28584 · cs.AI
CoRAL: Beyond the Sequentiality Bottleneck — 扩散-自回归混合多模态推理框架
自回归模型存在推理串行瓶颈，扩散语言模型可并行但语义连贯性不足。CoRAL 采用非对称规划-执行架构：扩散规划器并行生成 K 条推理轨迹，大型自回归执行器负责落地。
「扩散做发散、自回归做收敛」的分工非常直觉且工程友好，是混合架构里少见的角色清晰的方案。
推理架构扩散语言模型
arXiv 2610.28576 · cs.LG
The Token-Energy Law of LLM Decode
提出 Token-Energy 定律：用「活跃字节数」和「实际解码时间」两个核心维度，建立 GPU 板级每 token 能耗的紧凑可解释模型，用于指导高能效部署。
当推理成本开始按「焦耳/token」计价，这类可解释的能耗定律就是容量规划和硬件选型的标尺。
推理能耗系统
HuggingFace Daily · 7 票
On the Fragility of Tasks under Composition: Implicit Budgeting in Language Models
发现根本局限：模型在单 prompt 内处理多个任务时错误率显著上升，即使每个子任务单独都能可靠解决；这种退化无法用独立错误累积完全解释，暗示存在隐式的内部预算机制。
「每个都会，合起来就翻车」——对依赖复杂指令编排的 Agent 应用是直接警告，值得所有 prompt 工程师一读。
LLM 能力边界任务组合
HuggingFace Daily · 4 票
OverSeer: Multi-Agent World Models Beyond What Agents See
将视频世界模型扩展到多智能体需生成多个时间上、智能体间一致的视角流。OverSeer 用空间固定的辅助相机视角作为「世界中心表征」的代理，增强各智能体的自我中心视角。
固定辅助视角充当多智能体之间的「公共坐标系」，思路简洁，对多机器人协作仿真有直接借鉴价值。
世界模型多智能体

35B MoE agentic 模型，通过自适应能力组合推进长程问题求解，强调 agentic 编排、验证与开放式科学发现三项改进，不仅会做单任务，还会在执行中组织工作、修正路线。
