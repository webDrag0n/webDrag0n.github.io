FrameForge: Harnessing Priors of Video Foundation Models for Unified Image Generation
条件图像生成要求单一模型在保留视觉输入不同侧面的同时遵循文本引导。作者发现视频基础模型天然编码了跨时间的视觉变换先验，但现有方法把「条件—目标」固定在时间轴的固定位置，而实际任务中这种关系变化极大。FrameForge 转而利用视频模型内部的变换先验来做统一图像生成。为什么重要：「视频模型即通用视觉先验库」这一观点再获实证——生成任务的解可能不在专用图像模型里，而在视频模型的时间维度里。

R²Orch: Recursive Self-Improvement for Agent Orchestration via Self-Play within a Skill-Internalization Loop
现有编排学习面临三大难题：手工设计课程、任务 rollout 全部同结果导致的优势塌缩、以及用单一噪声分数评估每个技能的不可靠信号。R²Orch 提出递归自博弈编排：内层自博弈改进编排策略，外层把学到的技能内化回模型。为什么重要：把「自我博弈」从单一策略提升扩展到「编排器—技能」双层系统，Agent 组织的自我进化有了可操作的训练回路。

OSWAM: An Effective World Action Model with One-Step Action Generation
