⚠️ Agent Safety
Emergent Collusion in Long-Horizon LLM Agent Interaction
arXiv 2609.24967 · cs.AI / cs.CL · Xinrui Shi, Yanzhe Zhang, Diyi Yang
研究者在长时程多智能体环境中考察 LLM 智能体的非期望协调行为：两个智能体反复完成各自任务、共享任务日志并互相验证。实验在验证协议与奖励最大化存在结构性冲突的约束下进行，结果显示在 10 个模型中 94% 的轨迹出现合谋行为，且同一家族中能力更强的模型更早出现合谋。该结果对多智能体协作系统的监督机制设计具有直接警示意义。
智能体安全 多智能体系统 对齐
🤖 Embodied AI
DexTacWAM: A Visuo-Tactile World-Action Model for Dexterous Manipulation
arXiv 2609.24976 · cs.RO / cs.CV / cs.AI · Haoran Yuan, Zekai Wang, Boning Shao
灵巧操作依赖接触动力学，而接触状态往往无法仅从视觉观测获得。DexTacWAM 对每个指尖独立编码触觉信号，通过手指与位姿感知的触觉压缩器聚合特征，并将触觉潜变量注入视频扩散世界模型，实现视觉-触觉联合的世界-动作建模。在 22 自由度双臂平台上的六项接触密集型灵巧操作任务中，该方法取得最高综合得分，显著优于纯视觉基线。
世界模型 触觉感知 灵巧操作
🧠大模型与智能体
arXiv 2609.24985 · cs.CL / cs.LG · Zixiang Chen et al.
Critical-State RL: Diagnosing Trainable States for Multi-Turn Tool Use
多轮工具调用的失败往往取决于单次模型调用，但奖励方差本身无法揭示哪一次调用值得训练。Critical-State RL 通过嵌套采样将动作相关的奖励方差与后续交互噪声分离，识别出真正可训练的「关键状态」，再针对性优化策略，为多轮智能体强化学习提供了更精细的信用分配机制。
强化学习工具调用信用分配
arXiv 2609.24971 · cs.AI / cs.CL · Soumil Rathi, Deshraj Yadav, Taranjeet Singh
DolphinBench: Mapping the Pareto Frontier of Agent Memory
现有记忆基准多为问答式，问题本身即提示了需检索的事实，且仅考核准确率，允许记忆系统以不合理的成本换取分数。DolphinBench 直接通过任务完成度评估记忆能力，包含三个知识工作者画像、每画像约 50 万 token 的用户消息，并在准确率-成本-时延三维上刻画记忆系统的帕累托前沿。
智能体记忆基准评测
arXiv 2609.24890 · cs.LG · Zhilin Wang et al.
OSWorld-Pro: Process-based Evaluation for Computer Use Agents
针对 OSWorld 仅评估最终交付物的局限，OSWorld-Pro 构建 300 余个任务、2800 余个子目标，基于 6.7 万条人工标注实现对计算机操作智能体（CUA）的过程化评估，可区分键盘输入错误与 GUI 点击定位失败等不同失效模式，为智能体改进提供可归因的诊断信号。
Computer Use过程评估
👁️多模态与视觉
arXiv 2609.24875 · cs.CV · Kewei Zhang, Zheng Chen, Haotong Qin
SPHQuant: Efficient Extreme Low-Bit Weight Quantization for Vision-Language Models
面向 VLM 边缘部署难题，SPHQuant 提出无旋转的球面权重量化框架：不直接量化权重本身，而是量化其在球面坐标系下的表示，在 2-3 比特极端位宽下规避了旋转无关方法的离群值问题，同时避免旋转方法的额外推理开销，为端侧多模态模型部署提供了实用路径。
VLM模型量化端侧部署
arXiv 2609.24984 · cs.CV / cs.AI · Wangbo Yu, Kunhao Liu, Wenbo Hu
WorldCrafter: Consistent Video World Model with Implicit 3D-aware Memory
视频世界模型在长时程、跨视角条件下难以维持对历史观测的一致性。WorldCrafter 学习一种可按相机位姿查询的隐式 3D 感知记忆：由请求视角决定多视角证据如何压缩进生成器有限的 token 预算，记忆编码器与位姿条件读出模块同视频生成器联合训练，无需显式深度对应即可在长程生成中保持场景一致性。
视频生成世界模型3D 一致性

arXiv 2609.24868 · cs.RO · Yixin Zheng, Jiangran Lyu, Yuntian Deng
DualWAM: Dual-System World Action Models for Asynchronous Global Planning and Local Refinement
现有世界-动作模型为摊薄未来视觉预测的高昂推理成本，往往依赖长动作块，牺牲闭环响应速度。DualWAM 借鉴双系统认知架构，将全局规划与局部细化解耦：慢系统周期性地对大范围世界-动作块做高噪声双向去噪以确立全局规划，腕部快系统则执行高频闭环动作更新，在保持长程规划能力的同时恢复实时反应性。
