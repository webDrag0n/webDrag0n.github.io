🔥头条热点
Hot Topic · LLM Agent
The Wealth of Agents: Scaling Agentic AI Across Developers
当前智能体系统普遍由单一开发者全权构建与部署，这一模式限制了系统规模的进一步扩展。论文系统研究多开发者智能体系统（Multi-Developer Agentic Systems, MDA），论证多个开发者协作构建智能体系统是突破规模边界的关键路径，并给出相应的架构原则与协作机制设计。该工作为 Agent 生态从「单作坊」走向「分工市场」提供了概念框架。
热点 LLM Agent 多智能体系统
Hot Topic · 具身智能
Modeling and Understanding Neural Weights of Humanoid Policies with Diffusion
UC Berkeley 团队（Shankar Sastry 组）提出用扩散模型直接建模人形机器人控制策略的神经网络权重分布，而非沿用传统训练流程获得单一权重。研究开辟了「权重空间生成建模」这一新视角，有助于理解人形策略的结构特性，并为策略的快速生成、插值与迁移提供新工具。
热点 人形机器人 扩散模型 权重生成
🧠大模型与智能体强化学习
arXiv 2610.20597 · cs.AI, cs.LG
Co-Evolving Acting and Forecasting for Language Agents
针对语言智能体训练中长期 rollout 成本高昂、标准 Agentic RL 仅利用终端标量奖励的瓶颈，提出共演化行动与预测的训练框架，将中间步骤的监督信号显式纳入学习过程，显著提升样本效率与长程任务表现。
Agentic RL 语言智能体 长程任务
arXiv 2610.20572 · cs.LG, cs.AI · HuggingFace Daily Papers 上榜
Recovering Reliable Supervision via Critique-Guided On-Policy Distillation
指出在线蒸馏（OPD）的关键失效模式：教师模型在学生错误前缀下并不总能「恢复」至正确答案（recoverability 假设不成立），导致监督信号被学生错误污染。提出批评引导的在线蒸馏方法，在错误 rollout 上恢复可靠监督，提升蒸馏稳定性与效果。
在线蒸馏 RLHF 后训练
arXiv 2610.20516 · cs.CL, cs.AI, cs.LG
VASPO: Self-Distillation with Privileged Value Estimation
针对在线自蒸馏中监督信号仅反映局部 token 偏好、而非学生续写期望回报的问题，提出带特权价值估计的自蒸馏方法 VASPO，在 GRPO 框架之外提供更精确的信号标定，改进推理模型的后训练质量。
自蒸馏 GRPO 推理模型
👁️多模态与视觉
arXiv 2610.20538 · cs.CL, cs.AI, cs.CV, cs.LG, cs.SE
PrismaCoder: Pushing the Boundaries of Open Multimodal Code Intelligence through Decomposed Rubric Synthesis
多模态代码智能连接程序符号世界与其执行产生的视觉世界（图表、网页、动画、半结构化文档）。该工作通过分解式评分细则合成（Decomposed Rubric Synthesis）推进开放多模态代码模型的能力边界，缩小开源模型与专有模型在可交互代码产物生成上的差距。
多模态代码 开源模型 代码生成
arXiv 2610.20584 · cs.CV, cs.AI, cs.HC · HuggingFace Daily Papers 上榜
Player-1: Learning to Play from Synthetic Experience
面向计算机操作智能体在游戏场景中的泛化难题，提出从合成经验中学习游戏操作的 Player-1 框架。游戏以其视觉丰富性与机制多样性成为通用数字控制的严苛试金石，该工作探索了以合成数据替代大规模人类示教的训练管线。
GUI Agent 合成数据 游戏智能体
🤖具身智能与机器人
arXiv 2610.20442 · cs.RO
Towards Agentic Robots: Model, Data, Environment, and Harness
基础模型正驱动机器人智能的范式转移：从低层动作预测走向对数据采集、模型训练、任务规划与真实执行的目标导向编排。论文将这一新兴范式刻画为「智能体化机器人」（Agentic Robots），并从模型、数据、环境与支撑设施四个维度给出系统性综述与研究路线图。
Agentic Robot 综述 VLA
arXiv 2610.20609 · cs.RO
SafeDriveVLA: Navigation-Conditioned World Model Dreaming for Conflict-Aware End-to-End Autonomous Driving
视觉-语言-动作（VLA）模型在自动驾驶中将导航接口从固定指令集扩展至自由形式自然语言，但同时引入新的脆弱面：驾驶员指令疏忽可能诱发驾驶冲突。SafeDriveVLA 通过导航条件下的世界模型「想象」机制实现冲突感知的端到端驾驶决策。

📝 编辑点评

本日研究动态呈现清晰的「Agent 化」纵深推进态势：理论层面，多开发者智能体系统（MDA）的提出标志着 Agent 研究开始直面规模化协作的制度性问题，而非仅关注单体能力；训练层面，共演化行动-预测、批评引导蒸馏、特权价值估计三篇工作不约而同指向同一痛点——Agentic RL 的监督信号密度与可靠性，密集化、抗污染的训练信号正成为后训练研究的核心议题。具身智能方面，Berkeley 以扩散模型建模人形策略权重的工作开辟权重空间生成建模新方向，Agentic Robots 综述则为领域确立了模型-数据-环境-设施的四维分析框架。开源社区延续了「Agent 平民化」趋势，ESP32 控制 iPhone 项目以极低成本验证移动端 GUI Agent 的可及性，上下文工程类 Awesome 列表的持续活跃亦印证工程范式重心正从提示词转向上下文管理。整体而言，智能体从「单体能力」迈向「系统规模化」的叙事正在论文与开源两侧同步成形。
