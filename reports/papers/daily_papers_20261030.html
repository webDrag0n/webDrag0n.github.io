Heads of Security: Learned Attention Gates Improve Prompt Injection Robustness
HoS 在注意力头级别学习一组「安全门」，让每个头重新分配对可信指令与不可信数据的注意力，使模型可以「读」不可信内容而不「执行」其中注入的指令，在 Llama-3.3-70B 与 GPT-OSS-20B 上对比 SecAlign++、ASIDE 取得更优鲁棒性。为什么重要：提示注入是 Agent 时代的 SQL 注入，把防御下沉到注意力机制内部而非外挂过滤层，可能是更可持续的架构级解法。
