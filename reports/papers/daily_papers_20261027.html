arXiv 2610.31779 · HuggingFace Daily Papers
FLORA: An Open Model Suite for Scaling Robotics Data Engines
FLORA 开源一套面向机器人数据引擎规模化的模型套件，覆盖从数据采集到策略训练的关键环节。它的意义在于把「数据飞轮」从公司私有基础设施变成社区公共品，有望降低 VLA/具身智能研究的进入门槛。
Robotics Data 开源套件
arXiv 2610.31423 · HuggingFace Daily Papers
FocusVLA: Future-Intent Guided Dynamic View Routing for Vision-Language-Action Models
FocusVLA 提出以「未来意图」引导动态视角路由的 VLA 架构，让模型主动选择与下一步动作最相关的视觉区域。相较于「全图注意力」的暴力方案，这种意图驱动的稀疏视觉注意为实时具身控制提供了更高效的推理路径。
VLA 动态视角路由 具身推理
arXiv 2610.32969 · cs.RO · HuggingFace Daily Papers
DexPort: A Hand-Held Skill Interface for Dexterous Hand Data Collection
DexPort 提供一个手持式的灵巧手数据采集接口，让研究者可以在真实场景中直接采集手部操作技能。与遥操作或动作捕捉相比，这种「拿着走」的方案大幅降低了灵巧操作数据的获取成本，对训练可泛化的灵巧手策略具有直接价值。
Dexterous Hand 数据采集
