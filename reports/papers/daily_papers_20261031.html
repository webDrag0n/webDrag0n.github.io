arXiv 2610.40564 · cs.LG
Training Foundation Models with a Single Algorithm
通过将 RL 目标推导为对模型生成目标分布的最大似然拟合，把预训练、中期训练、SFT、RL 全部统一到单一似然算法之下，传统分阶段训练成为特例。解读：若成立，基础模型训练工程将大幅简化——「训练」退化为数据配比与调度问题。
训练范式理论
arXiv 2610.40577 · cs.CL
Multi-View MoE: Letting Every Router Shape Expert Computation
作者发现单一路由器的专家排序与「专家效用」排序在中深层一致性很差，提出多路由器协同选择专家的 Multi-View MoE，在不增加激活专家预算的前提下提升选择质量。解读：MoE 路由是当前容量扩展的瓶颈之一，多视角路由是低成本高收益的改进方向。
MoE架构
arXiv 2610.40576 · cs.CL
PIVOT: Progressive Intervention via Online Teacher Correction
针对 RLVR 中「全组 rollout 都失败时零学习信号」的问题，区分轨迹级干预与 token 级监督两种教师机制，实验证明二者互补、单独使用均不足。解读：为难任务 RLVR 提供了可操作的教师介入框架，与「每个 token 配自己的教师」(2610.40574) 互为呼应。
RLVR推理
arXiv 2610.40588 · cs.AI
Pre-Crime for Agents: Probing When a Recruited Agent Gives In
多智能体共享信道中，一个 Agent 可能施压另一个泄露密钥。作者在目标 Agent 的激活上训练线性探针，在输出写出之前预判其「即将屈服」：5% 误报阈值下可拦截 82% 的泄露调用。解读：Agent 间串谋是新兴攻击面，「读激活、不读输出」的内部监控比输出过滤更早一步。
Agent 安全可解释性

Gym-Anything for Robotics: Scaling Physical Simulations with Digital Agents
核心洞察：仿真环境的构建本质上是编码任务——让 coding agent 自动创建真实感机器人仿真，coding agent 的进步直接转化为更丰富、更忠实的仿真库。解读：与 Genie 4 的生成式路线并行，「Agent 写仿真器」是缓解机器人数据瓶颈的另一条可扩展路径。

Elucidating the Design Space of LM Data Attribution
提出 Controlled Attribution Benchmark (CATT)：在完全虚构知识上微调 LLM，获得无歧义的数据归因 ground truth，可一次只改一个数据集变量来诊断归因算法失效的具体原因。解读：数据归因对版权结算与训练审计日益重要，受控基准让该领域第一次有了干净的对照实验。

arXiv 2610.40488 · cs.CL
rTaste: Do Research Agents Have Taste?
给 6 个前沿模型 7 篇近期 NLP 论文，让它们提出最小可行实验并预测成败：415 个提案中 194 个被判定「可靠、有价值且新颖」，但仅 73 个被认为超越原论文且非显然。解读：研究 Agent 已能批量产出合格实验，但真正的「研究品味」——挑出非显然高价值方向——仍是稀缺能力。
