📝 编辑点评

今天最值得关注的是一个悄悄形成的共识：让 Agent 真正干活的瓶颈正在从「模型能力」转向「执行成本与接口」。CPU-ARC 和 LowRAM 一个从推理复用、一个从 KV cache 结构入手，指向同一个方向——未来的 Agent 系统里，昂贵的大模型只该出现在「非解不可」的时刻，其余交给缓存、压缩和小模型。这对商业化意义很大，意味着 Agent 产品的推理成本曲线还有数量级下降空间。

机器人方向今天信号密度极高。两篇论文（Agentic Manipulation Policies、Computer-Use Agents as Embodied Generalists）不约而同地质疑 VLA/WAM 这条 specialist 路线，主张回到「通用模型 + 数字软件接口」的 embodied 范式，这和当前 Figure、Apptronik、智元用真实场景数据堆量产能力的做法形成有趣对照——学术界在反思架构，工业界在堆数据，短期内后者似乎更占上风。此外软银/ABB 因中国审查考虑剥离中国业务，标志地缘政治正式成为机器人产业的核心变量，值得持续跟踪。建议读者把「数据规模 × 部署密度」作为下一阶段评估具身智能公司的核心指标。
