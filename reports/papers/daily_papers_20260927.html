RAPID: Robot Agentic Programming from Demonstrations
MIT（Jiayuan Mao、Leslie Kaelbling、Tomás Lozano-Pérez 等）提出 RAPID 框架，将代码智能体在复杂编程任务上的成功范式迁移至机器人系统：从人类演示中自动生成可执行的机器人程序。该方法打通了「代码智能体 → 机器人策略合成」的链路，为通用机器人编程提供了无需大量人工标注的新路径，是 LLM Agent 与具身智能融合的标志性工作之一。
热门cs.RO具身智能代码智能体

PoEM: Predicting RL Outcomes from Existing Policies
MIT CSAIL 与 NVIDIA 联合提出 PoEM：在基础模型进行计算密集且往往不稳定的 RL 后训练（人类对齐、正确性、指令遵循）之前，直接从现有策略预测 RL 训练的最终结果。该工作有望将昂贵的 RL 后训练从「试错流程」转变为「可预测流程」，对大模型训练成本控制具有直接的工程价值。

Rolling-WAM: World Action Models with Rolling Imagination
World Action Models（WAM）将动作生成与未来视觉预测耦合用于机器人操作，但每次重规划周期都需完成联合视频-动作去噪过程，延迟显著。Rolling-WAM 提出滚动式想象机制，在不牺牲预测质量的前提下大幅压缩决策延迟，使 WAM 类方法更接近实时操作场景的可部署形态。
世界模型机器人操作实时性
arXiv · cs.RO · 2026-09-24 · HuggingFace Daily Papers 收录
Coding Agents for Generalized Task and Motion Planning Problems
面向广义任务与运动规划（Generalized TAMP）：即使在完全可观测与对象中心状态下，离散决策与几何、运动学、动力学约束的紧耦合仍使 TAMP 极具挑战。该工作将编码智能体引入广义 TAMP 求解，由智能体自动生成并验证规划程序，是「LLM-as-planner」路线在机器人长程规划上的又一进展。
TAMPLLM 规划机器人
arXiv · cs.RO · 2026-09-24
AD-WM: Action-Discriminative World Models for Counterfactual Model Predictive Control
指出潜在世界模型的一个结构性缺陷：模型通常在事实转移预测上训练，而模型预测控制（MPC）需要从同一状态比较多个候选动作——事实误差低的模型未必能区分动作后果。AD-WM 提出动作判别性世界模型，面向反事实 MPC 优化动作间区分度，为世界模型在控制闭环中的可靠性提供了新的评估与训练视角。
世界模型MPC控制

arXiv · cs.CV / cs.LG · 2026-09-24
The Alignment Illusion in Multimodal Large Language Models
对多模态大语言模型中一个被广泛接受的解释提出质疑：逐层视觉-文本相似度的提升常被解读为语言模型逐步将视觉内容整合进共享表征空间的证据。作者指出该解读建立在未经检验的假设之上，并通过系统性分析揭示「对齐提升」可能是一种度量假象。该工作对 MLLM 可解释性研究方法论具有警示意义。
MLLM可解释性表征分析
arXiv · cs.CV · 2026-09-24 · HuggingFace Daily Papers 收录
WanPE: Towards Cinematic Prompt Enhancement for Modern Text-to-Video Generation
随着视频生成模型扩展至 30 秒级并忠实遵循复杂条件，文本提示词在很大程度上决定了生成质量上限。WanPE 提出面向电影级表达的提示增强框架，将原始用户意图系统性地扩充为包含镜头语言、光影与叙事节奏的结构化剧本式提示，显著提升现代文生视频系统的视觉叙事能力。
