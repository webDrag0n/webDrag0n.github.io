GLiDE: A Fast, Calibrated Decision Model Distilled from Reasoning Teachers
决策模型通过单次前向传播对候选答案打分，实现快速、置信度感知的决策，但推理能力可显著提升决策质量。GLiDE 探索将推理教师的能力蒸馏到决策模型中，兼顾速度与准确性。
决策模型蒸馏推理

HiSA: Sparsifying the Hidden Dimension of RoPE Attention in LLMs
HiSA 提出隐藏维度稀疏注意力，挑战注意力机制是否必须计算完整 dot-product 的假设。通过在隐藏维度上做稀疏化，有望在不显著损失性能的前提下降低注意力计算开销。
注意力机制稀疏化效率优化

MemFolder: Structure-Guided Memory Folding for Efficient Agent Memory Management
长期 Agent 面临外部记忆库不断膨胀的问题，检索成本和生成成本随记录数增长。MemFolder 提出结构引导的记忆折叠机制，将相关记忆压缩为紧凑结构，降低存储与检索开销。
Agent记忆管理效率

📝 编辑点评

今天最值得关注的方向是"推理能力的工程化落地"。Beam 的 501B 稀疏 MoE 技术报告证明了大模型可以在大幅降低推理算力的同时保持前沿能力，这对 Agent 规模化部署意义重大。GLiDE 和 AutoMaster 则代表了另一种思路——不是让模型更大，而是让模型更聪明地利用已有能力。机器人赛道本周进入"量产验证期"：智元 500 台 A3 部署、Agility 上市、现代全资收购波士顿动力、1X NEO 即将发货，这些事件共同标志着人形机器人从实验室走向工厂和家庭的拐点正在临近。开源社区方面，Agent 基础设施（记忆、技能、工具调用）继续成为最活跃的赛道，Hermes Agent、opencode 等项目的快速迭代预示着一个更开放的 Agent 生态正在形成。
