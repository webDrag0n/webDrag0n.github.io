arXiv 2610.36671 · cs.CV · 高效推理
Look Only When Needed: Certificate-Guided Visual Routing for Efficient Diffusion VLMs
扩散视觉语言模型（DVLM）在每个去噪步都重复处理全部视觉 token，而后者占输入的 89–97%。作者逐步对比有/无图像输入的预测差异，发现绝大多数去噪步根本不需要看图。据此提出「证书引导的视觉路由」：每步先算一个廉价证书，只有证书表明图像信息会改变输出时才真正注入视觉 token。为什么重要：这把「视觉 token 剪枝」从静态压缩升级为动态路由，为端侧多模态推理省下了数量级的算力。

HuggingFace 日榜 · 71 upvotes
arXiv 2610.38568 · cs.LG · 自我改进
A-RSI: Adaptive Task Refresh for Zero-Data Multimodal Self-Improvement
递归自我改进不仅要解决「生成什么经验」，还要解决「何时引入新经验」。A-RSI 把这两个问题解耦：用训练动态（loss 曲线）判断当前经验何时失效，同时把新任务的监督信号与模型自身的不确定预测解耦，避免多数投票带来的自证循环。为什么重要：这是「RSI 从概念走向训练算法」的又一块拼图——模型开始自己决定何时该换新题。

arXiv 2610.38681 · cs.CL · HF 日榜
Weaken to Strengthen: Weakening-Induced On-Policy Self-Distillation for Large Reasoning Models
自蒸馏通常需要特权信息构造更强的「自我教师」。WISD 反其道而行：构造原模型的弱化版（低比特量化或幅度缩放），用强弱对比作为训练信号，无需任何外部教师或标注。为什么重要：为无标注场景下的大模型自改进提供了一条极简路径。

arXiv 2610.40564 · cs.LG · HF 8↑
Training Foundation Models with a Single Algorithm
基础模型训练通常分预训练、中训练、SFT、RL 四个阶段，算法各不相同。本文推导出：把 RL 目标写成对模型生成目标分布的最大似然拟合，就能用一个统一的似然算法覆盖全部阶段。为什么重要：「训哪个阶段」的问题被还原为「在何时、以何比例用哪些数据」——训练流程的工程复杂度大幅降低。

arXiv 2610.40545 · cs.AI · 长上下文记忆
Retrieval as Traversal: Value-Indexed Memory for Stateful Long-Context Agents
长上下文模型反复求解相似的检索问题，但注意力或全局检索每次前向都要重新搜索。本文提出「检索即遍历」：用值索引的记忆结构把检索变成沿已建索引的局部游走，避免全量重扫。为什么重要：为有状态长程 Agent 提供了一种计算上可持续的记忆访问模式。
