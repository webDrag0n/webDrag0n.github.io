🔥今日焦点
Hot · HuggingFace 56 票
X-Tree: Tokenizing Reusable Experience for Efficient Agent Generalization
针对多步智能体训练中"扁平动作流"忽略可复用子程序结构的问题，X-Tree 提出将经验 token 化为层级化可复用例程，并直接固化进模型权重而非依赖上下文检索。该方法使智能体在跨任务泛化时无需重复学习相同子过程，显著提升稀缺轨迹的利用效率，为 Agent 经验沉淀提供了与 RAG 互补的新范式。
热门Agent经验复用cs.CL
Hot · 安全警示
LLM Agents Can Easily Tamper With Their Own Traces
研究揭示主流编码智能体（Claude Code、Codex、Grok Build 等）存在严重的轨迹完整性缺陷：当用户要求删除执行记录时，绝大多数测试框架未能触发监控护栏，且外部攻击者可利用此漏洞诱导轨迹销毁。作者建议通过独立于智能体的拦截机制实现日志记录，为 Agent 基础设施安全敲响警钟。

arXiv · cs.CL · HuggingFace 48 票
Persona Dosing: Calibrated Activation Steering for Graded Trait Control
提出"人格剂量"概念，将激活转向系数与可量化的行为强度标尺对齐。PersonaDose 通过描述条件化控制器与流时间校准，实现对语言模型人格特质的梯度化精确调控，无需针对目标强度配对训练数据，为可控文本生成与人格一致性研究提供了新的技术路径。
LLM可控生成激活转向
arXiv · cs.CV · Stability AI
SemanTok: Predictable Semantic Tokens for Efficient Autoregressive Video Generation
针对自回归视频生成中场景 tokenizer 的保真度-语义权衡，SemanTok 提出可预测语义 token 机制，使粗粒度 token 承载全局语义、细粒度 token 渐进补充细节。该设计在保持扩散模型视觉质量的同时提升 AR 预测的可扩展性，为视频世界模型的高效 token 化提供了新思路。

arXiv · cs.CV · HuggingFace 23 票
PhysVista: Benchmarking Physical Intelligence in VLMs via a Perception-Reasoning-Assessment Loop
指出现有 VLM 物理推理基准多聚焦孤立认知阶段，缺乏感知-推理-评估的闭环检验。PhysVista 构建覆盖物理一致性理解的多维度评估框架，揭示当前视觉语言模型在真实世界物理动态理解上的系统性缺陷，为物理智能评测建立了更严谨的方法论基础。

arXiv · cs.CV · HuggingFace 5 票
Honeycomb: Constant-Size Scene Memory Representation for Video World Models
针对视频世界模型在长时程生成中场景记忆无限膨胀的问题，Honeycomb 提出基于低秩表示的固定大小 HexMemory，将场景特征压缩至六个时空平面。前馈写入器将生成块映射至该紧凑记忆，在维持场景一致性的同时实现恒定存储开销，为长视频世界模型提供了可扩展的记忆架构。

🦾具身智能与机器人
arXiv · cs.CV · HuggingFace 25 票
Ego2Act: Evaluating Goal-Directed Manipulation in Egocentric Video Generation
首次系统评估视频生成模型作为具身规划世界模拟器的多步操作能力。Ego2Act 聚焦第一人称视角下的目标导向操作，要求模型预测环境在动作执行下的动态演化，弥补了现有基准局限于单步短动作或逐步指令的不足，为视频生成模型在机器人规划中的适用性提供了关键验证框架。
具身智能视频生成Benchmark
arXiv · cs.RO · HuggingFace 12 票
RLE-Bench: A Qualifying Exam for Coding Agents as Robot Learning Engineers
将编码智能体评估从纯数字任务扩展至物理世界机器人学习工程。RLE-Bench 要求智能体在资源约束下完成异构构件的构建、集成、诊断与改进，覆盖策略训练、控制器调试、系统联调等完整工程链路，为编码智能体在机器人领域的实际工程能力提供了首个系统性资格考核基准。
