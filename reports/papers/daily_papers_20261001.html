🔥 世界模型 / World Model
Waypoint-1.5: A Real-Time Video World Model for Consumer Hardware
面向消费级硬件的实时扩散式交互世界模型。与一般视频扩散模型不同，交互式世界模型须在严格延迟与吞吐约束下响应密集用户控制。该模型在 10 万小时、覆盖数百款游戏的控制对齐视频数据上预训练，可根据完整键鼠输入生成可交互画面，标志着世界模型向端侧实时部署迈出关键一步。
热门cs.CV世界模型视频生成
arXiv:2609.36071 · cs.AI
LongCat-DeepResearch Technical Report
深度研究系统技术报告：将增强版 LongCat 模型与多智能体工作流结合，产出证据扎实的综合研究报告。工作流将全局规划与细粒度调查分离，多个规划智能体先行探索外部信息源并迭代出可执行的研究规范（ResearchSpec），随后由研究智能体分节撰写并在章节层面协调修订，为长文本深度研究智能体提供了系统化工程范式。

arXiv:2609.38164 · cs.RO
Rho: A Foundation for Efficiently Adaptable VLA Models
面向双臂操作的开放权重 VLA 模型家族，定位于「数据轻量化的下游任务适配」。在 YAM Box、UR AI Trainer、FR3 Duo 三类代表性双臂平台上进行系统性消融，兼顾通用视觉语言能力与跨本体精确控制，为实验室与产业界的 VLA 适配提供了开放基础。
开放权重VLA双臂操作
arXiv:2609.36774 · cs.RO
LexiconVLA: Learning Reusable Atomic Action Codebooks for Unseen Tasks
诊断发现：任务完成率高并不意味着原子动作在不同任务上下文间被一致执行。LexiconVLA 提出可检索的原子动作词表——全局码本捕获共享交互结构，细节码本刻画细粒度执行差异，从而实现跨任务的动作复用，提升 VLA 在未见任务上的泛化能力。
VLA动作码本泛化
arXiv:2609.36118 · cs.AI
The Layer Mystery of VLA: An Information-Theoretical Analysis of VLA Latent Interface
VLA 策略通过潜层接口连接预训练视觉语言骨干与动作头，但接口应暴露哪些骨干层长期缺乏定论。该工作在 LIBERO 与 CALVIN 两个基准、三种预训练模型上，对冻结骨干的单层选择与多层融合进行信息论层面的系统分析，为 VLA 架构设计提供可复现的实证依据。
VLA信息论架构分析
arXiv:2609.37089 · cs.CV
Real2Gym: Building Gyms from Videos, Bringing Skills to Robots
智能体化的 Real2Sim2Real 框架：将人类与机器人示范视频重建为视觉对齐、物理可交互的仿真环境（Gym），在仿真中习得技能后迁移回物理机器人，打通了「真实视频→可复用机器人技能」的完整链路，缓解遥操作数据采集昂贵、难以扩展的瓶颈。
Sim2Real机器人学习视频重建

arXiv:2609.38008 · cs.CV
HybridCUA: Learning to Orchestrate GUI and CLI for Computer-Use Agents
指出现有计算机使用智能体（CUA）的两条路线均有局限：纯 GUI 交互低效易错，接入应用专属 API 则工程成本高且难以跨应用扩展。HybridCUA 主张下一代 CUA 应学习 GUI 与命令行（CLI）的协同编排，为通用计算机使用智能体提供了可扩展的新范式。

今日研究图景呈现清晰的双主线：其一，世界模型与视频生成加速走向「可交互、可实时、可端侧」——Waypoint-1.5 在消费级硬件上实现控制对齐的实时生成，预示世界模型从演示走向可用基础设施；其二，具身智能研究从「堆数据」转向「结构化复用」——LexiconVLA 的原子动作码本、VLA 潜层接口的信息论分析、Real2Gym 的 Real2Sim2Real 闭环，均在回答「如何以更少的真实数据获得更强的泛化」这一核心命题。开放权重的 Rho 与纯 C++ 推理引擎 vla.simd 进一步降低了 VLA 的研究与部署门槛。智能体侧，HybridCUA 的 GUI/CLI 协同编排与 LongCat-DeepResearch 的多智能体研究流水线，显示智能体工程正从单点能力走向系统级编排。开源生态方面，Robot-Use Agent、GUI Agent 安全等垂直 awesome 列表的涌现，反映出社区知识组织正随细分领域的成熟而精细化。
