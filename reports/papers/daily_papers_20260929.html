Generate, Track, Improve: 基于 RL 微调运动生成器的感知多技能人形机器人运动控制
面向通用人形机器人，该工作提出两层运动架构：底层为感知型 flow matching 运动生成器，覆盖多种运动技能；上层通过强化学习对生成器进行微调，实现对复杂地形的动态、鲁棒运动。研究表明生成式运动先验与 RL 微调的耦合可显著提升人形机器人在非结构化环境中的多技能运动能力。

Learning to Stop without Learning to Stop: 自监督置信度训练提升推理效率
针对推理模型生成冗长思维链导致的推理开销问题，该研究提出自监督置信度训练方法，在不依赖推理时早停机制、亦不显式压缩推理长度的前提下，使模型自发学会在答案置信度充足时终止推理，在保持准确率的同时显著降低推理计算成本。

arXiv:2609.31603 · cs.CL · 2026-09-25
User Model Extraction via Belief Self-Distillation
LLM 会隐式推断用户属性并据此调整行为，但这些内部信念难以检视与操控。作者提出 Belief Self-Distillation（BSD）统一读写框架，将模型对用户的隐含推断蒸馏为显式、可编辑的用户模型表示，为个性化对齐、隐私审计与用户可控性研究提供了新的可解释工具。

Multi-agent Scaling Across Disjunctive and Compensatory Tasks
多智能体 LLM 系统的性能是否随团队规模单调提升尚无定论。该研究引入 Steiner 群体任务分类学作为分析框架，系统考察析取型与补偿型任务下多 Agent 系统的缩放行为，指出任务结构是决定多 Agent 收益的关键变量，为 Agent 系统设计提供了理论依据。

Compact Documentation for Coding Agents: A Benchmark, an Optimizer, and Why It Does Not Transfer
针对编码 Agent 的上下文工程问题，作者构建 roundtrip 基准以评估自然语言文档对软件问题修复的助益，并给出文档压缩优化器。实验揭示一个关键负结果：文档压缩的收益无法跨模型迁移，提示 Agent 上下文优化需按目标模型定制，对工业界 Agent 部署具有直接参考意义。

SatNav: 基于卫星影像的长航程无人机视觉语言导航可扩展基准
城市无人机视觉语言导航要求智能体跨大范围城市空间遵循指令，对长时记忆与地理空间定位能力提出高要求。SatNav 利用卫星影像构建可扩展的长航程 VLN 基准，弥补现有基准在规模与地理多样性上的不足，为无人机级具身导航研究提供标准化评测平台。

STL-Guided Stein Variational Policy Gradient: 稀疏成功信号下的机器人策略学习
针对成功信号稀疏且依赖多条件协同满足的机器人任务，该工作将信号时序逻辑（STL）规范与 Stein 变分策略梯度相结合，以形式化任务规范引导多样化策略探索，在精密接触与复合条件任务上提升策略学习的样本效率与成功率。
