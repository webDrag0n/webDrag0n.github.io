OpenAI 发布 ChatGPT Wallet：AI Agent 可以替你安全地「掏钱」了
OpenAI 于 11月13日 官宣 ChatGPT Wallet，首次让 Agent（dots）在不接触真实卡号的前提下代用户完成支付，每笔交易都需要用户单独的安全确认（生物识别）。首批面向美国 18+ 的 Pro 订阅者开放，已与 American Express、Mastercard、Visa 达成底层合作，并保留了卡片原有的积分、拒付等消费者权益。
这是 Agent 经济真正意义上的「最后一公里」——支付通道打通后，AI 不再只会「说」，而是能「买」。 Visa/Mastercard/Amex 三家卡组织同步站台，说明传统金融已经默认 Agent 支付会成为下一个高频场景。
