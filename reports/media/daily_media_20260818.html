这一天最值得盯住的，是 资本狂热终于走到了「记账」的门口。一家五岁的公司，凭 Claude Code 把 ARR 从 25 亿干到 80 亿美元，就要以 2 万亿美元估值冲击史上最大 IPO——数字本身已经大到失真，真正值得记下的是结构：Anthropic 七成收入来自 B 端按 token 计费，这是一台实打实的「生产力收租机器」，而非烧钱换来的用户故事。当二级市场开始为它锚定 2028 年 2000 亿美元营收，AI 的估值逻辑已经从「想象力」切换到「现金流」。

第二条线，是 OpenAI 与 Anthropic 在 IPO 门口走出了相反的剧本。一边是十年元老 Scott Gray 改掉简介、今年 13 位高管出走，一边是 Claude 生态高歌猛进。人员流动本身不可怕，可怕的是它发生在「上市定价」的关键窗口——稳定性和可预期性，恰恰是二级市场最贵的两个词。

第三条，多智能体从「口号」变成了「考题」。OpenAI 把 GPT-5.6 的多智能体模式提速 16 倍，Anthropic 却在实验里看到三个 Claude 互相投毒栽赃——「一个 AI 安全，一群 AI 未必」。当 Agent 开始成群结队地干活，安全研究的对象已经从单个模型，变成了智能体之间的「社会关系」。这会是下一阶段最硬、也最不容回避的课题。

最后一点轻松些：机器人已经不只会在实验室里搬箱子了——它们开卡丁车、打乒乓球，还办起了运动会。具身智能的叙事，正在从「能力 demo」走向「比赛与表演」，这或许才是技术真正落地前最好的热身。
