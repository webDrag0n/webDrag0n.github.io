AMD 82 亿美元全股票收购 World Labs，李飞飞出任执行副总裁兼首席科学家
当地时间 9 月 28 日，AMD 宣布以约 82 亿美元（约合 550 亿元人民币）全股票交易收购空间智能公司 World Labs，交易预计 2026 年底完成。李飞飞将加入 AMD 担任执行副总裁兼首席科学家，直接向 CEO 苏姿丰汇报。此举被视为 AMD 押注物理 AI（Physical AI）与世界模型端到端能力的关键布局，也是世界模型赛道迄今最大规模的交易。

Anthropic 发布 Claude Sonnet 5.5：速度提升约 30%，定价维持 Sonnet 档位
在 OpenAI DevDay 开幕前一日，Anthropic 推出中端模型 Claude Sonnet 5.5。官方称新模型运行速度显著提升、使用成本较上一代大幅下降；多方实测显示其性能接近 Opus 5.5，直逼 GPT-6 Astra。安全层面，Anthropic 首次在 Sonnet 系列部署高阶网络安全防护机制，并加入反蒸馏分类器以抵御大规模 API 能力提取。

OpenAI 因安全考量叫停 GPT-6.1 Astra 发布
OpenAI 于 9 月 28 日表示，因内部测试显示下一代模型 GPT-6.1 Astra 未达到公司安全标准，决定放弃原定 10 月的发布计划。该模型原计划进入 ChatGPT 与 Codex，定位于以更少人工干预完成复杂端到端任务。叠加近期多起智能体失准（agent misalignment）事件，业界评论认为：对下一代智能体而言，能够在必要时暂停、回滚甚至放弃模型，与提升模型能力同等重要。

至知创新研究院开源 IQuest-Q1：320B 稀疏 MoE，激活仅 15B
IQuest Research 开源新一代大语言模型 IQuest-Q1，采用稀疏 MoE 架构，总参数约 320B、激活参数约 15B，主攻代码、软件工程与复杂智能体任务。实测中可凭单条 Prompt 生成完整小游戏、完成十万步三体问题数值求解，并能定位 RL 训练数据中的隐藏空格缺陷。团队自进化框架 ModularRSI 已登上 Hugging Face 热榜，模型权重已在 GitHub 与 Hugging Face 同步开放。
