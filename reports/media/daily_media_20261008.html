OpenAI 公开 722 篇内部模型数学成果：准黎曼猜想、BSD 猜想、霍奇猜想均在列
OpenAI 通过 GitHub 仓库集中发布由一个未公开内部模型生成的 722 篇数学手稿，归并为 372 组结果，覆盖数论、代数几何、统计力学等 17 个方向。其中声称将 ζ 函数及狄利克雷 L 函数的无零点区域推进至实部大于 7/8，并给出有理数域上希尔伯特第十问题的不可判定性证明，部分成果附 Lean 形式化验证。模型在约 4000 个研究问题上进行尝试，单项成果平均算力约相当于 ChatGPT Pro 连续思考 3 小时。OpenAI 同时与普林斯顿高等研究院合作制定 AI 数学成果的发布规范。多位菲尔兹奖得主表示关注但未对其正确性背书。

自进化也会过拟合：Google 等提出 RRSI，为智能体自改进施加正则化
针对递归自我改进（RSI）范式，Google 等机构提出正则化递归自改进框架 RRSI（Regularized Recursive Self-Improvement）。研究指出，智能体 Harness 的自改进过程同样存在过拟合风险——在特定任务分布上过度优化会导致泛化能力下降。RRSI 通过正则化搜索、候选版本隔离管理与评审筛查机制，实现可审计、可控的自我改进，为近期 RSI 热潮提供了方法论层面的冷静注脚。

VA-Bench 揭示大模型空间智能的「执行断层」：看懂不等于做对
VA-Bench 评测基准以「观察—推理—行动—修正」闭环测试 12 个多模态大模型在真实机器人操作中的空间智能：14 类任务、280 个经物理验证的场景。结果显示，头部模型在目标识别定位上接近满分，但完整任务成功率仅约一半，Qwen3.8-max、Opus-5 与 GPT-5.6 均呈现显著的动作执行断层。该基准为具身智能研究提供了更严格的度量工具。

三星与上海交大提出 RoboICL：无需参数更新的具身上下文学习
RoboICL 提出一种基于 GPT-6 Astra 的具身上下文学习框架，将示范上下文与交互记忆分离，采用统一的「观察—动作—回执」语法，在无需机器人专用参数更新、无需训练 VLA 模型的前提下实现机器人控制，并在多项机器人操控评测中全面领先。该工作表明通用多模态大模型的上下文学习能力可直接迁移至具身操控场景。

MIT 与 Meta 发布 DREAM：可生成图像并自我评判草稿的统一模型
MIT 与 Meta 联合发布 DREAM 模型，兼具图像理解与文本到图像生成能力，其亮点在于「自我评判」机制——模型可对自身生成的粗略草稿进行评估与迭代，直至产出最优版本。该机制带来更强的视觉能力与图像质量，配合外部重排序器时生成速度提升约 10%，为自主式图像生成系统提供了新方向。

Meta 将 TBE 内核从 CUDA 迁移至 FBTriton：推荐模型前向提速 1.28 倍
Meta 贡献者已将推荐系统关键的 Table Batched Embedding（TBE）内核从 CUDA 全面替换为基于 Triton 的 FBTriton，实现前向传播最高提速 1.28 倍、反向传播提速 2 倍，并显著提升开发者效率。该迁移是 Meta 构建开放 AI 基础设施路线的重要一步，亦验证了 Triton 在生产级工作负载中的成熟度。

📝 编辑点评

10月7日的信息密度集中于一条主线：AI 正从「能力展示」转向「科研产出与成本结构的深水区」。OpenAI 一次性公开 722 篇数学成果，无论最终验证结果如何，其意义在于将 AI 辅助数学研究从单点突破推向规模化产出，并与普林斯顿高等研究院共建发布规范——这标志着 AI4Science 开始进入学术建制化阶段。与之对照的是产业端的理性收缩：Meta 与微软大幅削减 Claude 用量、OpenAI 主动腰斩 API 定价，共同指向推理成本已成为行业竞争的决胜变量。研究层面，RRSI 为自进化过热降温，VA-Bench 戳破空间智能的「纸面聪明」，均属方法论层面的必要冷思考。整体判断：模型能力仍在快速上行，但评价坐标已从 benchmark 分数转向可验证的科研贡献与可持续的单位经济学。
