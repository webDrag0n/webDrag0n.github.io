第 05 篇 · 第二条件：预测

预测：世界模型与主动推理

Prediction as the Mathematical Equivalent of Existence

May 17, 2026 Reading Time: 22 min Category: Active Inference & World Models
可替代之身 · AGI 六条件系列 05 / 09
TL;DR

Friston 的自由能原理（Free Energy Principle, FEP）给出了一个数学上惊人简洁的论断：任何持续维持自身存在的系统必然最小化感知预测误差[1]。这意味着"预测能力"不是智能的一个可选模块，而是存在的数学等价条件——一个具备身体（第 04 篇）的系统，若不对未来建模，就必然解体。本文把 Helmholtz 的无意识推断、Rao & Ballard 的 predictive coding、Ha & Schmidhuber 的 World Models、LeCun 的 JEPA 与 Pearl 的反事实推理统一在主动推理框架下，并指出当前 LLM 的"预测"停留在 token 层面，离 state-level / model-level 世界模型仍有结构性差距。

01活下去等价于预测：一个 19 世纪的命题

"生物体的感知本质上是一种无意识推断。" ——这是 Hermann von Helmholtz 在 1867 年《生理光学手册》[2]中提出的命题。感知并不是把外部刺激"原样"传入脑的被动过程；它是一个生成模型持续对感官输入做出假设、然后与真实输入进行比对的过程。我们"看到"的是模型的输出，不是视网膜上的像素。

Helmholtz 的这一命题在一百五十年后被两条独立的线索严格化。一条是神经科学：Rao & Ballard 1999 年的 predictive coding[3]指出视觉皮层的分层结构可被解释为高层预测低层、低层把预测误差回传高层的信号流；这一假设在其后获得了大量实验支持[4][5]。另一条是理论物理与信息论：Friston 把"最小化预测误差"推广为一条更一般的原理——任何维持自身存在的系统必然最小化其感知的变分自由能[1]。

这一原理对 AGI 的重要性怎么强调都不为过。它把"预测"从"一个有用的认知技能"提升为存在的结构性必然。承接第 04 篇：一旦系统具备身体（不可逆时间 + 可耗资源 + 持续维护），它就不得不预测——因为若不预测，它的行动将无法把资源消耗维持在生存阈值之上。

\( \text{Existence}(x)\ \implies\ x \text{ minimizes } \mathcal{F}[q(s), p(o, s)]\ \text{ where } \mathcal{F} = \mathbb{E}_q[\log q(s) - \log p(o, s)] \)

这里 \(s\) 是外部世界（与自身）的隐状态，\(o\) 是感知，\(q(s)\) 是系统对 \(s\) 的后验信念，\(p(o,s)\) 是系统的生成模型。\(\mathcal{F}\) 是变分自由能——在凸优化意义下，\(\mathcal{F}\) 最小化即 \(q(s)\) 逼近真实后验 \(p(s|o)\)，也即预测误差最小化。Friston 的论点是：任何持续维持马尔可夫毯（第 04 篇意义上的"身体"）的系统都在事实上执行这一最小化——否则它会解体。

Philosophical Interface · 哲学接口

这一命题与 Heidegger 的"在世存在"[6]有一个深刻的对应。Dasein 之所以能"理解"世界，不是因为它拥有一组关于世界的陈述知识，而是因为它已经把自己投射入未来（Heidegger 称之为"投射性"，Entwurf）。Friston 的自由能原理把这一现象学描述翻译为数学：系统与世界的关系本身就是一个持续的预测行为；没有预测就没有在世。这也与 Clark 的"预测心智"命题[7]完全一致。

02自由能原理与主动推理环

自由能原理有一个关键的工程化推论：系统可以通过两条路径最小化 \(\mathcal{F}\)——改变信念或改变世界。前者是感知推断（更新 \(q(s)\)），后者是主动推理（选择动作 \(a\) 使未来观测更符合预测）[1][8]。这两条路径共同构成主动推理环（active inference loop），在 Fig 05-A 中可视化。

把第 04 篇的身体定义代入主动推理框架，我们得到一个关键结论：身体 + 主动推理 = 存在最小单元。没有身体，预测无处落地；没有预测，身体无法维持。两者在结构上互为对方的充要条件。任何一个能被称为"在场"的系统都必须同时具备这两项——这也正是第 04、05 两篇在本系列中紧挨的逻辑原因。

Formal Box · 自由能最小化的两种路径

最小化 \(\mathcal{F}\) 可被分解为：(a) 感知推断——调整 \(q(s)\) 使之接近真实后验 \(p(s|o)\)，这对应权重/信念更新；(b) 主动推理——选择 \(a^*=\arg\min_a \mathcal{F}(a)\)，使未来观测分布更符合先验偏好。两路径都是 \(\mathcal{F}\) 的梯度下降，差别仅在变量：前者对信念求梯度，后者对动作求梯度。工程上这两路径分别对应"更新世界模型"与"规划动作序列"——正是任何持续 Agent 都必须同时做的两件事。

03三层预测对象：外部、他者、自我

主动推理要求系统对三个层级的隐状态建模。这三个层级共享数学结构但在工程上有截然不同的挑战：

  • 外部世界（Environment）——物理/社会/市场环境的动力学。典型工程实现：World Models[9]、Dreamer[10]、AlphaZero 的 MCTS 搜索[11]。
  • 其他主体（Others）——他人意图、竞争对手策略、用户偏好。需要"心灵理论"（Theory of Mind）层面的递归建模：我预测你预测我预测你…… Premack & Woodruff 的工作[12]是其心理学奠基；Rabinowitz 等人的 ToMnet[13]是工程化尝试。
  • 自我（Self）——对自身状态、策略、能力边界、知识盲区的建模。这是元认知的根基（第 08 篇展开）。Metzinger 的"自我模型理论"[14]把这一层级的预测视为意识的核心机制。

这三层在数学上共享自由能框架，但在工程上需要不同的架构。外部层的主流实现是隐空间状态转移模型（Dreamer[10]、JEPA[15]）；他者层需要心灵理论网络（ToMnet[13]、multi-agent RL[16]）；自我层的工程对应物尚处早期，Reflexion[17]、Self-Refine[18]可视为最初尝试。三层之间的递归耦合（我预测你预测我……）仍是未解工程问题。

04World Models 的工程谱系：从 Helmholtz 到 LeCun

把自由能原理的预测要求具体化到工程层面，形成一条清晰的 World Models 谱系。这条谱系跨越一个半世纪，但核心命题始终一致——智能体内部必须持有一个可以模拟外部世界动力学的生成模型。

值得特别指出的是 LeCun 的 JEPA（Joint Embedding Predictive Architecture）[15]：他明确把"自回归 token 预测"（即当前 LLM 的范式）作为批评对象，主张真正的世界模型必须在抽象隐空间而非 token 空间做预测——因为原始像素/token 空间中细节不可预测，而抽象状态空间可预测。这一观察揭示了下一节的核心问题。

05LLM 预测的层级缺口：token ≠ state ≠ model

当前 LLM 本质上是一个 token 级的自回归预测器：给定前 \(n\) 个 token，预测第 \(n+1\) 个。这在规模足够大时展现出惊人的涌现能力，但也有一个结构性局限——预测的对象始终是 token 分布，而非世界状态或世界模型本身。把预测能力按抽象层级分成三级：

  • Token-level 预测——在词表上给出下一个 token 的分布。当前 LLM 的原生能力。
  • State-level 预测——给出"世界下一步的状态"（游戏局面、机器臂位置、市场价格、用户下一需求）。需要抽象隐状态表示与状态转移模型。
  • Model-level 预测——对世界的动力学模型本身的预测：环境规则如何变化、对手策略如何更新、生产系统如何演化。需要元学习与反事实推理。

LLM 通过巨大的训练分布，在许多情况下能模拟前两级预测——但本质上是通过 token 层面的相关性涌现出的 state-level 行为，而非显式的 state 表示。Pearl[19]在其因果层级理论中给出了一个清晰的形式化：预测、干预、反事实构成三级因果阶梯，能在第一级工作的系统未必能达到第三级。model-level 预测必然涉及反事实（"若我选择动作 A 而非 B，世界会如何不同？"），这在纯 token 模型中无法可靠实现[20]。

这一层级缺口对 AGI 的含义是：要成为能替代组织的持续个体，LLM 必须被嵌入一个 state-level 与 model-level 预测能力都被显式构造的架构。Hassabis 等人[21]在其神经科学-启发 AI 综述中明确预测了这一方向。Tenenbaum 的"核心知识 + 概率程序"纲领[22]、LeCun 的 JEPA[15]、Chua 等人的 PETS[23]都是从不同角度补齐这一缺口的尝试。

"Prediction at the token level is not prediction of the world. It is prediction of the way the world has historically been described." — 对 LeCun[15]与 Pearl[19]批评的压缩

把本篇合到前面两篇：第 04 篇建立了身体，第 05 篇确立了预测作为身体的数学伴生条件。但这两条件仍然指向单次行动——系统在某一时刻对下一时刻预测并做出反应。要让预测在长时间尺度上累积为连贯的认知结构，系统必须持续存在。这就是第 06 篇的主题。

Series Bridge · 章节衔接

身体（04）→ 预测（05）→ 持续（06）。前两条件确立了"主动推理环"的空间结构，下一条件确立其时间结构：一个只在当下闭合、却不跨越时间的循环，依然不是在场。
